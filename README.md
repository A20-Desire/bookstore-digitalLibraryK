# 📚 Bookstore Digital Library

A full-stack MERN application that lets users browse, manage, and discover books online.  
Built with **MongoDB**, **Express.js**, **React**, and **Node.js** — designed for smooth navigation, clean UI, and easy expansion.

---

## 🚀 Features
- 📖 Browse a collection of books with detailed info  
- 🔍 Search and filter by title, author, or genre  
- ❤️ Add books to your personal favorites list  
- 🧾 Manage book entries (create, edit, delete)  
- 🔐 User authentication and secure access  
- 💡 Responsive design for all devices  

---

## 🛠️ Tech Stack
**Frontend:** React, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Version Control:** Git & GitHub  

---

## ⚙️ Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/A20-Desire/bookstore-digitalLibraryK.git
````

### 2. Navigate into the project

```bash
cd bookstore-digitalLibraryK
```

### 3. Install dependencies

* For backend:

  ```bash
  cd Backend
  npm install
  npm start
  ```
* For frontend:

  ```bash
  cd ../my-app-frontend
  npm install
  npm start
  ```

### 4. Environment variables

Create a `.env` file in the `Backend` folder with:

```
MONGO_URI=your_mongodb_connection_string
PORT=5000
JWT_SECRET=your_secret_key
```

---

## 🌍 Deployment

Frontend hosted on **GitHub Pages** or **Vercel**
Backend hosted on **Render** or **Railway**
